# 数据源层 (Data Source Layer)

给 8 个只读看板与交易引擎供数的所有外部数据通道的统一语言。本文件只管术语，不管接口与实现。

## Language

**数据腿**:
一条从外部源落到一张库表的独立供数通道，自带源、更新节奏与口径。迁移、对账、退役的基本单位。
_Avoid_: 数据源（泛指网站时混用）、接口

**口径**:
一条数据「怎么算出来」的语义约定——加权方式、复权基准、统计范围、单位、定盘还是加权。两条腿可对接的前提是口径一致，或差异已被量化。
_Avoid_: 格式

**痛点腿 / 无痛腿**:
现源有实测不稳定记录（限流、被拦、端点已死、稀疏）的腿 / 现源工作正常、仅为统一而考虑换源的腿。

**平移类迁移**:
换源但不改变口径与覆盖面的迁移。验收 = 重叠期对账通过。
_Avoid_: 替换、切换

**升级类迁移**:
换源同时改变口径或覆盖面的迁移（如杠杆成分沪市→沪深两市）。与平移类分开成批、排在平移类之后，不与平移混在同一提交。
_Avoid_: 优化

**退役**:
没有活的消费方或活的端点的数据腿，从回填编排中摘除；表与代码留盘存档，不删。
_Avoid_: 删除

**全量重灌**:
用新源把一条腿的历史整段重拉、衍生指标全部重算，新旧不拼接。比值类关键腿的默认迁移方式。
_Avoid_: 重拉

**增量接续**:
历史留旧源、新源只管此后增量。仅当重叠期对账确认口径一致后允许，月频宏观腿的默认方式。
_Avoid_: 拼接

**对账**:
在新旧源重叠区间逐期比对数值、按各腿容差判定、产出口径差量化报告的验收动作。精确族（官方同源数）容差为零；口径差族不设硬门、只量化不拦。
_Avoid_: 校验、比对

**回退链**:
tushare 为第一源、旧源依次兜底的调用顺序；tushare 失败时降级到旧源，不炸整腿。
_Avoid_: 容错

**引擎冻结**:
引擎决策链所读的表（ETF 日线、ETF 份额）不参与任何换源迁移的边界约定——换源即改变回测底座，须另立项目重做验证。
