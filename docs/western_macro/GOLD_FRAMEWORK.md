# 影响黄金走势的思维框架（JZ《西方经济》提炼）

> 来源：`docs/Billibili-JZ/western_economy/` 转写稿。提炼的是**框架与因果链**，不含具体点位预测。
> 用途：黄金阶段定位器 + 宏观框架看板的参考底座。只读诊断，不喂引擎（ADR-0001）。

## 0. 一句话总纲
**长期多头 = 美元/美债信用衰败的镜像；中期方向 = 美债利差/期限溢价；短期节奏 = 美元指数（海外美元松紧）。** 判阶段不看单一指标，看**因果链是否被破坏**。

---

## 一、长期 / 结构性层（决定大方向 · 地基）

### 四大长期驱动（2025-09-01 明确）
1. **美元信用崩塌** — 美元武器化（2022 俄乌 + SWIFT 制裁）→ 各国意识到持美元有政治风险 → 央行抛美债囤金。
2. **美债信用崩塌** — 美债不断膨胀 = 套现未来的钱花到现在 → 美元相对所有商品贬值。**"不是黄金在涨，是美元在贬值。"**
3. **逆全球化** — 1991→2022 全球化行情结束 → 长债需求端萎缩（养老金/险资刚性兑付需求减弱）→ 美债 30 年多头终结 → 资金转黄金。"逆全球化一旦确立，黄金是 10 年甚至更长多头。"
4. **地缘冲突** — 避险 + 战争扩大财政赤字 → 印钱 → 美元信用受损。

辅项：实际利率 / 长天期国债（黄金对手盘 = 长债）、期限溢价、央行购金、化债→通胀→滞胀、黄金重估/TGA、香港黄金清算系统（抽实体 → 纸黄金紧缩）。

**退出条件**：新货币体系形成（他以"台湾回归后半年到一年"作粗略标志）才卖；此前不空仓、不做空。

### ★「向心坍缩 vs 入不敷出」（2026-07-28 核心结构性框架）
- **向心坍缩** = 流动性问题（流量 / 流向 / 流速），资金各回各家、套息萎缩、外汇掉期承压。**只是导火索，不是根源。**
- **入不敷出** = 盈利模式被证伪（资本回报 < 资本成本）。判断一切泡沫的关键字——运河/铁路/电力/互联网/**AI**。
- **公式**：流动性紧缩 + 盈利强 = 抄底机会（2020 新冠）；流动性紧缩 + 盈利弱 = 泡沫破裂（2008 次贷、中国房产）。
- **对黄金**：纯流动性危机 → 黄金被连带抛但会恢复；真正改变范式的是**美国 AI "入不敷出" 被证伪** → 美元体系"盈利能力"（靠 AI 拉高 GDP 化债）崩 → 黄金超级周期根本驱动。美国"一根筋两头堵"：保 AI 须放水（美元跌、金涨）；保美元须收缩（AI 泡沫破、金先跌后涨）→ **两条路都利黄金**。

## 二、因果链 / 数据层（他实际看的数据）

**核心因果链**：扩表印钱 → 美债超发 / 美元信用↓ → 央行抛美债买金 + 抗通胀 + 避险 → 实物交割需求↑ → 可流通现货不足 → 挤兑 → 价格飙升。

> ⚠ 他**不直接盯** 10Y TIPS / breakeven 这类"教科书实际利率"。实际利率逻辑通过 **SOFR/GOFO/JLR 租赁市场 + 美元美债信用**间接表达。

### 数据指标分层（L1–L4）
| 层 | 指标 | 用法 |
|---|---|---|
| **L1 长期驱动**（稳·定方向） | 美元信用（DXY 趋势/美债需求）、美债信用（债务规模/利息占比/央行持仓）、逆全球化、地缘 | 大方向地基 |
| **L2 中期供需** | 央行购金量、CME 月度交割（house vs customer）、ETF 持仓、开采量 vs 需求 | 实物需求强度 |
| **L3 短期择时**（**会失效·须标注**） | **GOFO Bid/Offer spread**（大幅快降 = 买点）、JLR=SOFR−GOFO、租赁利率期限结构（2 月 vs 12 月倒挂 = 紧缺）、COMEX 库存、未平仓合约、金银比、投机仓位 | 择时/紧缺 |
| **L4 炒作预警** | 实物重量 vs 市值斜率背离（市值斜率 > 重量斜率 = 炒作）、投机仓位极值、Gamma squeeze 信号 | 泡沫预警 |

### 金银关系
- **黄金** = 货币属性 / 抗通胀工具（长期持有可不看盘）；**白银** = 工业 + 金融双强（须看盘 + 止损）。
- **金银比**：爆冲（直线拉升）→ 白银补涨；暴跌 → 警惕白银见顶崩。纸白银/实物白银比率 > 纸黄金 → 白银挤兑风险更大。

### 方法论原则
- **宏观可预测（周期），微观难预测且规律常变** → "不要刻舟求剑"，多组交叉验证，别单押一组。
- 长期多头者**别看**短期数据（看了紧张）；波段操作者才看全量。
- **"涨跌同源"**：投机驱动的上涨必因投机衰弱而跌（2026-02 金银暴跌 = gamma squeeze 反转实证）。

## 三、战术 / 阶段层（短期节奏 + 阶段判定）

### 四因素模型（2026-08-07，权重随阶段变）
1. **美元指数 DXY**（筑底完成后**排第 1**；= 海外美元松紧代理；海外央行/机构是黄金主买家）。
2. **利率政策**（加息/降息/缩表/扩表；扩表 = 印钱 = 金涨最直接）。
3. **经济数据**（就业 + 通胀；须拆"假数据"——劳动参与率 50 年低点造成的统计假象等）。
4. **油价**（筑底前中等，筑底后弱化）。

底层：**10Y = 对手盘，2Y = 机会成本，10Y−2Y 利差 = 中期方向**（"10Y 涨 + 2Y 降 = 更低机会成本对冲更大风险 → 央行必买金"）；**期限溢价**（信任驱动 = 利好；通胀驱动 = 假利空）。

### 阶段语言 + 判定（四层交叉验证）
阶段词：**筑底 / 底部震荡 / 完成筑底（反弹准备）/ 震荡上涨 / 禁止加仓区（高位）/ 回调下跌 / 冲高回落（A 杀）/ 长期趋势上行**。

判定四层：
1. **底层**（牛市在否）：美债规模趋势 + 逆全球化状态。
2. **中期方向**：10Y−2Y 利差方向 + 期限溢价方向。
3. **短期位置**：DXY 路径 + 数据真伪 + 地缘状态。
4. **操作切换触发**：站稳关键位 + DXY 反弹后再下杀路径确认 + 数据配合 → **切换"波段 → 持有"思路**（08-07 整期核心动作）。

> 2026-07-07 "是否筑底"实证：用 9 信号交叉验证（美债总额 vs 金价 / 10Y−2Y 利差 / 10Y 买盘 / 金·标普比 / 租赁利率突冲 / COMEX 交割↑但库存不增 / ETF 极值流出 / 美银调查"估值正常" / 历史回调形态）→ 判"阶段性底部"。

### 双向防守（2026-04）
**既防太悲观（底部加仓），也防太乐观（警戒线 4800 以上禁加仓、高成本者减仓、带利润防守）。"不能拿钱袋子赌政治。"** 阶段不同，操作指令相反。

### 底与顶的锚（2026-05-28）
**底 = 央行何时买；顶 = 华尔街杠杆资金何时进场。** 偏好"慢慢磨上去"——涨太快被杠杆资金盯上 → A 杀。

## 三·补、阶段定位器 v2（已实现 · `gold_locator.py`）

把上面的四层判定落成规则,出「阶段 + 驱动三栏 + 置信度 + 操作建议」。**修复 v1 失败(分不清牛市回调 vs 终局底)** 的关键 = `bull_intact`:

- **L1 底层(bull_intact)** = `央行购金>0 AND (期限溢价1年↑ OR 实际利率1年↓)`。用 **1 年结构性趋势**(非 3 月),不被短期波动带偏。
  - bull_intact=True → 还在超级多头 → 价格上的"回调/筑底"都精炼为 **"牛市回调(加仓位)"**(非终局底)。
  - bull_intact=False → 底层存疑 → 操作转谨慎。
- **L2 中期方向**: 2s10s / 实际利率 / DXY 的近 3 月趋势(显示用)。
- **L3 短期位置**: 价格 5 阶段(复用 `stage.gold_stage_snapshot`)+ 投机净多分位(≥85% 泡沫)+ 商业净空分位(≥85% 逼空)+ COMEX 库存(<−10% 紧缺)。
- **阶段精炼**: bull_intact+回调/筑底 → "牛市回调(加仓位)"; 头部+投机泡沫 → "头部/泡沫风险"+warning; 头部+商业逼空 → warning 逼空临界。
- **置信度** = `阶段强度 × 驱动一致度 × (bull_intact?1.0:0.8)`(信号清晰度, 非 JZ-edge)。band ≥0.6 强 / 0.35-0.6 中 / <0.35 弱。
- **操作建议(双向防守)**: 阶段×bull_intact → 条件化指令(筑底+bull=分批加仓; 反弹初期+bull=切持有不空仓; 头部=禁加仓减仓; 回调+bull=加仓位)。

入口 `gold_locate(store, asof=None)` → dict(stage/stage_note/bull_intact/regime/drivers{底层,中期,短期}/confidence/action/warnings)。看板「🥇黄金阶段定位器」section。

**当前实证(2026-08-09)**: 反弹初期 / bull_intact=True → "切波段→持有,回调加仓不空仓不做空"(与 JZ 2026-08-07 原话一致,纯数据推出) / 信心中(实际利率↑逆风)+warning 库存紧缺。
