## 定位

**第七看板（只读旁路）**：中国本土宏观的观测层，与「宏观框架看板」（western_macro = 海外宏观因果链）对称——
本仓库至今没有本土宏观层。**永不喂交易引擎**；先行代理未过 event-study 礼遇前一律为**观察项**，
不出现「预测/信号」措辞（回测已证明：M2 拐点本身的 edge 在公布滞后下几乎归零，见
`data/m2_timing_study.html`）。

**与指数择时的关系**（2026-08-25 更新：⑪ 已从指数择时看板移除，**本看板①为货币条件唯一入口**；
其数据腿仍由 backfill_index --money 承载、纯核心 tracker/money_conditions.py 留仓）。复用
`tracker/money_conditions.py` 纯函数与 `china_money_supply`/`china_tsf` 表——零新数学，只加观测面。

## 决策记录

- **命名**：「国内宏观」（与宏观框架=海外宏观 对仗，四字合仓库风格）；「社会数据」语义模糊（易误解为
  人口/民意）弃用；「货币与信用」太窄（装不下远期实体数据）弃用
- **⑪ 不迁移**（2026-08-24 决策，**2026-08-25 推翻**：用户要求移除——重复展示无益,①为唯一入口；
  纯核心/验证器/数据腿留仓不变）
- **数据源纪律**：akshare/免费无 key 优先；探针不过=待补，不硬凑
- **v1 探针门**：Phase 0 结果决定 v1 section 2 装哪些腿——不承诺全装
