# A 股观点预登记台账（claims ledger）

**理念**（同西方宏观台账 ADR-0001 的轻量平移）：把"主流观点"在**说出时点**登记成
可证伪的 claim——内容、失效条件、观察窗在登记时固化，git 历史即预注册证明；到期结算，
给观点打分。对抗的是支撑位/目标价类话术的不可证伪结构（"撑住了是支撑有效，跌破了看下一个支撑"）。

**登记规则**：
1. claim 必须翻译成**可结算事件**（价格阈值 + 时间窗 + 结算判据），不许留解释空间
2. 登记后失效条件与观察窗**不可修改**；结算结论只许填，不许改
3. 结算时同时记录当时的市场行为量价语境（供 event-study 回溯）

**配套实证**：`scripts/validate_support_break.py`（平台顶+前低两类规则选位的守住 vs 破位
前向二阶矩研究）。已得结论（2026-08-15，上证综指 58 例）：破位确认后 **20 日实现波动显著
抬升**（19.9% vs 守住 14.5%，bootstrap 90%CI 不含 0）；**回撤中位数与方向胜率不分离**——
支撑位是观察坐标/温度计，不是买卖信号，永不喂交易引擎。

## Claim 002 · 商品动量快腿对映射周期股有前向信号价值（看板提速改版附带主张）

| 项 | 内容 |
|---|---|
| 登记日 | 2026-09-05 |
| 来源 | 自家 2026-09 商品看板提速改版（grilling 设计树 Q3：快信号以观察项上+排期验证）；逻辑源头=「商品价领先周期股业绩」方法论 + 宋鸿兵《大宗商品大风暴》叙事 |
| Claim | 商品期货 20 日动量 ≥±10% 触发后，对应映射周期股未来 20 日**跑赢观察池等权**（即快腿不只是提醒，还能指导买入时机） |
| 可证伪化定义 | event-study `scripts/validate_commodity_speed.py`：事件=品种 20日动量 ≥+10% / ≤−10%（point-in-time，每品种 120 交易日冷却）；结果=映射个股 10/20/60 日收益 − 观察池等权同窗收益；基线=同一批股全部交易日（每 5 日抽样）。**判据（跑数前预登记）：20日超额中位差 ≥ +1pp 且胜率差 ≥ +3pp → 有信号价值；否则温度计** |
| 观察窗 | 回溯全样本（商品日线 2020-01 起 / 个股日线 2021 起），首跑即结算 |
| 关联事件 | 首跑 2026-09-05：事件 112 个（向上67/向下45）× 映射股 33 → n=259 事件×股样本 |
| 风险预案（幕 0 预承诺） | 若判"温度计"：🚦 横幅快腿仅用于**研究排队**（提前看、提前研究），禁止当买入触发器；不喂引擎；不升级为推送 |
| 结算 | **温度计非开关**——20日超额中位 **−2.60%**（胜率 39%）vs 无条件基线 **−0.85%**（45%），中位差与胜率差双双不达标且方向为负：追商品动量买股系统性**跑输**。快腿价值=更早进入研究队列（改版目标 Q1 即此），非择时 |
| 结算日 | 2026-09-05（首跑即结算） |
| 结算语境 | 焦煤/原油/LPG 处战争溢价行情中（偏离分位 95-98%），样本含 2021 锂潮/2022 煤炭/2026-01 碳酸锂极端区；结论与 M2拐点/地量/支撑位三项既有实证同方向——**宏观与量价叙事在 A 股周期股上均无短窗择时 edge** |

## Claim 003 · 季报高业绩池 8 年 70% 场合跑赢所有宽基（陈氏方法论战绩声明）

| 项 | 内容 |
|---|---|
| 登记日 | 2026-09-12 |
| 来源 | 重远投资观（陈老师）星球问答图片6（2026-08-02）：「股池……从过去 8 年的历史看，大概能在 70% 的场合跑赢所有指数（50,300,500,1000，双创等），但依然有 30% 的场合会跑输部分甚至大部分指数」；方法论提炼存档 docs/stock_pool/MANUAL_REVIEW.md |
| Claim | 季度高业绩股票池（营收+扣非双高增长地板 + PEG/PB 两轨估值门 + 风险筛 + Top-N，随预告/快报/正式报三环逐股状态机进出）在持有到下期披露调整的节奏下，约 70% 的窗口跑赢**全部**主流宽基指数 |
| 可证伪化定义 | `scripts/validate_high_earnings_pool.py` 状态机回放（point-in-time 无前视）：窗口=报告期首个环事件日→下期首个环事件日；池=成员区间收益等权（入/出=事件次日开盘 T+1）；对照=上证综指/上证50/沪深300/中证500/中证1000/创业板指/科创50。**判据（跑数前预登记）：跑赢全部宽基的窗口占比 ≥60% 视为与声明方向一致（70% 留样本噪声带），≤50% 视为证伪；消融臂（去估值门/去风险旗）同报** |
| 观察窗 | 回溯已有数据（正式报 8-16 期 × 三环 ≈ 20-40 窗，**小样本**——结论只能作「样本内观察」）；前瞻滚动：每季正式报截止后加窗复核 |
| 关联事件 | 首跑 2026-09-12 与看板重写同批；回放近似口径见验证器报告注记（归母统一口径/股本恒定近似/历史无 ST 名单） |
| 风险预案（幕 0 预承诺） | 若判「证伪/温度计」：看板措辞保持「观察项」，不出现任何信号化用语；方法论保留为**筛选漏斗**（给候选不给买卖点）——漏斗价值不依赖跑赢指数声明成立 |
| 结算 | **样本内未获支持（证伪方向，n=8 小样本）**：8 窗全胜率 **38%**（3/8 跑赢全部七宽基），未达「与声明方向一致」线（≥60%），远低于声明的 70%。绝对收益为正：池中位 **+3.5%/窗**——输给的是最强基准不是亏钱。消融：三臂胜率同 38%，但**去估值门中位 +5.0% vs 全门 +3.5%**（本样本内估值门付出 ~1.5pp——高增长贵股继续涨的窗口吃掉门的收益，与「贵的筛掉」直觉相反；n=8 不足以定论）。数据闸门修正：预告面板每期 ~30-40 行公告日早于报告期末的上游错标行已剔除（剔除后窗口 6→8、首事件 2024-09-30 起合法） |
| 结算日 | 2026-09-12（首跑即结算；数据窗 2024-09~2026-09，8 期正式报 × 三环） |
| 结算语境·终审（2026-09-13 样本扩展至 9.5 年） | 用户指令将回放从 8 期扩到 **38 期（2017Q1→2026Q2，2017=陈老师文档「初入权益类资产」之年）**：数据腿扩至 2015 起面板+4869 只历期过地板者 11 年日线/分红（覆盖不以幸存者为条件）。**终审：37 窗全胜率 32%、池中位 −1.2%/窗——按预登记判据（≤50%）证伪**，与声明的 70% 方向相反；消融长期反转：**去估值门 39%/中位 +2.0% > 全门 32%/−1.2%——PEG 门长期是负贡献**。逐窗纹理：2017-2019 与 2022-2024 大幅跑输（小盘高增长被结构性绞杀），2019Q1(+39%)/2021Q3/2024Q3 后大幅跑赢——**8 窗期的 75% 系 2024Q3 后样本期运气**。已知偏差注记：历史 ST 名单不可回放（回放含后来戴帽的高预告垃圾股→老窗向下偏）；零成本乐观向。**结论：作为「跑赢所有宽基」的声明不成立；看板价值回归「候选生成+人工复审漏斗」（该价值不依赖本 claim）。前瞻滚动继续** |
| 结算语境·补记（2026-09-13 V8.1 复算） | 用户指令改用**Top-100 容量+逐日组合模拟**（散户可实现口径：任意时刻持仓=当前过门股票按 PEG 升序前 100、事件次日开盘进出、等权日内再平衡、零成本）复算：**全胜率 75%、池中位 +7.0%/窗**——越过 ≥60% 判据线、方向与声明一致；消融：去估值门 62%/去风险旗 62%（中位 +5.6%）/市值P80 62%——估值门贡献 +13pp 胜率。**口径敏感度警示**：V8.0（全部过门者等权段平均）38% vs V8.1（Top-100 逐日）75%——edge 主要来自 **Top-100 集中度**（最便宜 PEG 前 100 的精选），而非「全部高增长股」本身；陈氏原策略即精选池，V8.1 更贴近声明对象。两口径同 n=8 小样本，均含零成本乐观假设；前瞻滚动继续 |
| 结算语境 | 样本期为 2024-2026 结构性行情（创业板指/科创50 多窗领涨→「跑赢全部 7 指数」门槛极高）；价格覆盖 3615 只（sina 3 年日线）；回放统一归母口径+股本恒定近似（见验证器报告注记）。**前瞻滚动继续**：每季正式报截止后加窗复核，窗数 ≥20 后再对照判据；风险预案已执行——看板措辞全程「观察项」无信号化用语 |
